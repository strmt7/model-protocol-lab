# Reference

The reference is the authoritative, complete description of the
tool's surface. If a summary anywhere disagrees with the reference,
the reference wins.

## Command reference

- **[Usage](../USAGE.md)** — the complete reference: the fixture
  schema (§1), `doctor` (§2–§3), `run` and its budgets (§4–§6),
  installation for contributors (§7), every probe (§8), fixture
  authoring (§9), the interactive debugger (§10), `diff-backends`
  (§11), `diff-reports` (§12), `verify`, `pack` and the determinism
  self-audit (§13), and the surface-noise probe (§14).
- **The catalog** — the 29 format families are enumerated by the
  tool itself: run `model-protocol-lab catalog` for the exact,
  current list as JSON. The catalog command is the reference for the
  catalog; prose lists elsewhere are summaries of it.
- **[Security and data handling](../SECURITY.md)** — the trust
  boundaries, the audit findings and their resolutions, and the
  handling rules for checkpoints, fixtures and reports.
