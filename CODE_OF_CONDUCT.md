# Code of conduct

This project exists to measure things carefully and say plainly what the
measurements do and do not show. Discussion here — issues, pull requests,
and any project space — is held to the same standard: be accurate, be
direct, and argue with the evidence, not with the person.

## Expected behaviour

- Criticize claims, code, and measurements as hard as the evidence
  warrants; never attack a contributor personally.
- State uncertainty as uncertainty. A retracted claim, corrected with
  evidence, is a contribution, not a failure.
- Welcome newcomers' questions; answer the question that was asked.
- Keep private information private: no publishing of credentials,
  private model files, or anyone's personal data.

## Unacceptable behaviour

- Harassment, insults, or discriminatory language directed at a person.
- Deliberate misrepresentation of results, sources, or other people's
  work.
- Spam, off-topic promotion, or disruption of issue and review threads.
- Publishing others' private information without their consent.

## Enforcement

Report conduct problems through GitHub's reporting tools on the
relevant issue, comment, or profile, or by opening an issue marked
`conduct` if the matter is public. Reports are read by the maintainer,
who may edit or remove content, close threads, or block accounts that
violate this code. Security vulnerabilities are not conduct reports —
use the private route named in `docs/SECURITY.md` for those.

This code applies in all project spaces and in public spaces when a
participant is representing the project.
