Prompt-boundary canonicality

For every stored rendered prompt × greedy completion, the lab re-encodes the concatenated text and requires the joint encoding to equal the recorded prompt_ids + completion_ids. A mismatch is the Prompt Boundary Problem: the tokenizer re-segments the text at the prompt/completion seam, so the ids the model saw are not what the stored text would reproduce. 0 of 10 usable observations diverge (overall rate 0.0%).

certificate Every usable observation re-encodes exactly: the run's templates are boundary-canonical on this tokenizer.

Chat-marker isolation

Each hostile marker string was injected into user text and the checkpoint tokenizer's control-token ids were counted before and after.
